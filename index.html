JSON 查询与导出实战指南：告别繁琐代码，用 SQL 玩转 JSON

在日常开发中，我们经常需要处理第三方 API 返回的巨型 JSON 文件，或者从爬虫抓取的 JSON 数据中提取关键信息。传统的做法是写一段临时的 Python/Node.js 脚本来解析，或者将其导入 MySQL/MongoDB 数据库。但这些方式往往费时费力。

本指南将带你了解如何利用我们这款纯前端工具，像操作数据库一样，直接用 SQL 语法 查询 JSON，并将其转化为 Excel / CSV 表格，大幅提升你的工作效率。

一、 核心功能实战：JSON 转 SQL 查询

当你在左侧选中一个数组节点（例如数据中常见的 result 或 data 数组）时，上方会自动出现 SQL 查询编辑器。我们的工具内置了轻量级 SQL 引擎，支持绝大多数日常所需的查询语法。

1. 基础提取：SELECT

假设你的 JSON 数据长这样：

[
  { "id": 1, "name": "Alice", "role": "admin", "age": 28 },
  { "id": 2, "name": "Bob", "role": "user", "age": 34 }
]

用法： 你不需要提取所有的冗余字段，只需要用 SELECT 指定你需要的列名即可：

-- 只提取姓名和角色
SELECT name, role FROM data;

2. 条件过滤：WHERE

如果你想筛选出特定的数据，可以使用 WHERE 子句。支持标准的比较运算符：=、!=、>、<、>=、<=。

-- 找出年龄大于 30 岁的用户
SELECT name, age FROM data WHERE age > 30;

-- 找出角色为管理员 (admin) 的用户
SELECT * FROM data WHERE role = 'admin';

3. 模糊匹配：LIKE

当你需要搜索包含特定关键字的内容时，LIKE 是绝佳选择。使用 % 代表任意字符。

-- 找出名字以 'A' 开头的用户
SELECT * FROM data WHERE name LIKE 'A%';

-- 找出邮箱包含 'gmail' 的用户
SELECT * FROM users WHERE email LIKE '%gmail%';

4. 多条件组合：AND / OR

你可以使用 AND 和 OR 组合多个过滤条件。

-- 找出年龄大于 25 且角色是 admin 的用户
SELECT * FROM data WHERE age > 25 AND role = 'admin';

5. 结果排序：ORDER BY

如果数据是杂乱无章的，你可以使用 ORDER BY 进行升序（ASC，默认）或降序（DESC）排列。

-- 按年龄从大到小排序
SELECT * FROM data ORDER BY age DESC;

-- 按角色升序，如果角色相同则按年龄降序
SELECT * FROM data ORDER BY role ASC, age DESC;

6. 分页限制：LIMIT 与 OFFSET

面对上万条数据，你可以只取前几条进行预览。OFFSET 可以用于实现类似分页的效果。

-- 只看前 10 条记录
SELECT * FROM data LIMIT 10;

-- 跳过前 20 条，取接下来的 10 条（第 3 页）
SELECT * FROM data LIMIT 10 OFFSET 20;

二、 如何将 JSON 导出为 Excel 或 CSV？

JSON 嵌套复杂的结构往往让人头疼，而将其扁平化并导出为表格，是进行数据分析最直接的方式。本工具提供了一套完整的“JSON 转 Excel”流水线：

1. 智能识别并生成表格

你只需要在左侧点击包含多条记录的数组节点，右侧面板会自动识别其结构并渲染成数据表格。无论字段有多少个，都可以通过横向滚动查看。

2. 勾选与过滤（专属列）

很多时候，JSON 里有几十个字段，但你只关心其中的四五个。点击表格上方的 「⚙️ 列」 按钮，在弹出的面板中，勾选你需要的字段。这对于减少表格宽度、提高阅读体验极其重要。

3. 一键复制或下载

筛选完毕后，点击上方的工具栏按钮：

  • 📋 复制 (TSV)：直接将数据以制表符（Tab）分隔的形式复制到剪贴板，你只需要打开 Excel 粘贴（Ctrl+V），数据就会完美对齐到各个单元格中。
  • ⬇️ CSV / TSV：如果你需要生成文件发给同事，点击下载即可获得一个标准的表格文件。

4. 为什么下载的表格中文不乱码？

很多开发者遇到过：导出的 CSV 文件用 Excel 打开后，中文全部变成了乱码。这是因为普通的 UTF-8 编码没有包含 BOM 头。我们的工具在生成文件时，自动在文件开头加入了 BOM 标记（\uFEFF），确保 Excel 能准确识别 UTF-8 编码，从此告别乱码烦恼。

三、 进阶技巧：处理复杂嵌套与生僻字段

1. 无限层级展开与大文件支持

如果你的 JSON 层级极深，左侧的结构树支持按需展开。即使数组有几千条，工具每次也只渲染 200 条，并在底部提供一个 “▼ 加载更多” 的按钮。这种“懒加载”机制保证了无论文件多大，浏览器都不会卡死，内存占用始终保持在极低水平。

2. 一键定位与搜索

如果你在页面上看到一个奇怪的报错码或者数字（比如 47754），想要知道它在 JSON 的哪个位置。你可以直接将这个数字输入到左侧的搜索框。工具会瞬间扫描整个 JSON，并列出所有匹配的路径（如 $.result[728].organicTraffic）。点击结果，即可精准跳转并高亮该节点。

3. AI 智能字段翻译

如果你接手了别人写的系统，或者抓取了国外的接口，你可能会看到满屏幕的 intentCommercialPositions、serpFeaturesTrafficCost。这太折磨人了！

本工具内置了基础词汇库。如果你发现有些词不认识，点击左上角的 「✨ AI 翻译」，配置你自己的 API Key（支持 DeepSeek、ChatGPT 等），AI 会在几秒钟内识别出所有生僻的业务词汇，并将其翻译为符合行业语境的中文，永久缓存在你的浏览器中，极大地提升了阅读效率。

四、 常见问题解答 (FAQ)

Q: 我的 JSON 文件有几十 MB，这个工具能打开吗？会卡死吗？

A: 不会卡死。传统的格式化工具会尝试一次性渲染所有 DOM 节点，导致浏览器内存溢出崩溃。本工具只渲染你当前视野内和已展开的节点，所以打开超大文件依然十分流畅。

Q: SQL 查询支持 JOIN 或 GROUP BY 聚合函数吗？

A: 目前内置的引擎为了保证极速的纯前端体验，专注于单表的核心查询功能（SELECT, WHERE, ORDER BY, LIMIT）。暂不支持多表 JOIN 和 SUM/COUNT 等聚合操作。你可以将查询结果导出后，在 Excel 中进行聚合计算。

Q: 我的 JSON 数据包含公司机密或用户隐私，安全吗？

A: 绝对安全。本工具纯前端运行，没有后端服务器，所有解析、查询、导出均在你的浏览器（JavaScript 引擎）本地完成。你甚至可以按 F12 打开网络面板，或者断开网络连接使用，没有任何数据会被发送出去。

Q: 如果 JSON 格式有语法错误无法解析怎么办？

A: 在导入时工具会明确提示语法错误的具体位置（如第几行第几列缺少逗号）。如果你已经加载了数据，可以点击左侧的「📝 编辑 JSON」，在弹出的代码框中进行修改，修改完毕后点击应用即可重新解析。
