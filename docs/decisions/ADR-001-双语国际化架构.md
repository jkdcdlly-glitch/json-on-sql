# ADR-001：双语国际化架构（主体英文 + 运行时自动切换）

- **编号**：ADR-001
- **日期**：2026-11-11
- **状态**：已接受
- **体量级别**：L2

## 背景

项目原为纯中文界面。目标市场包含全球开发者（英文搜索量更大），但中文用户也不能丢。
无构建工具链、无框架，纯原生 JS，需要轻量可维护的 i18n 方案。

## 候选方案

- **方案 A**：维护两套静态页面（index.html + index_en.html）
  - 优点：SEO 各自独立、实现直白
  - 缺点：内容双份，每次改页面要同步两处，长期漂移风险高
- **方案 B**：单页 + JS 运行时切换（i18n 词典 + data-i18n 标记 + 自动语言检测）
  - 优点：内容单源；词典集中；浏览器语言自动判断（zh* → 中文，否则英文）；手动选择持久化 localStorage
  - 缺点：非默认语言的文案在首帧后才替换（微闪烁）；SEO 上非英文内容对爬虫可见性弱

## 决策

采用方案 B：英文为页面静态主体与默认语言，中文通过 `i18n.js` 运行时注入。

## 代价与接受

- 中文首帧有一次文案替换闪烁——工具类页面可接受
- 中文内容 SEO 弱化——由页面内中文长文（运行时注入）+ 中文关键词 meta 缓解，主战场放英文关键词

## 后续验证

- i18n key 完整性校验（动态/静态 key 与 en/zh 词典比对）
- 语言检测单测：zh-CN/zh-TW → 中文，en-US/ja/fr → 英文
- 相关 bug 记录：BUG-001（词典模板换行）、BUG-002（tr 遮蔽，本决策引入的副作用）
